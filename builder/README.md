# storybook_ds_builder

Gerador de funções `mergeNomeDaClasse` para o pacote **storybook_ds**, a partir da anotação `@StorybookModel`.

Uso típico é como **dev_dependency** do app de exemplo ou do app que define stories, com `build_runner` e um `build.yaml` que limita `generate_for` aos arquivos anotados.

Consulte o README principal do repositório (seção *Reflection-free* / *Sem reflexão*) e o projeto em `example/`.
